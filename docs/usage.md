# 使い方の細かいところ

操作の一覧は [README](../README.ja.md#使い方) にある。ここはその補足。

## グローバルショートカットは持っていない

⌘C 2 回で足りるし、`⌘⇧T` のようなアクセラレータは他アプリと衝突して「登録できない」だけの
設定項目になりがちなので落とした。ウィンドウを隠したあとの出しどころはトレイアイコンで、
終了もそこから。

## 前面表示について

以前は常に最前面に出していたが、他のアプリを触っている間も被さり続けるので普通の
ウィンドウに戻した。⌘C 2 回やトレイから開いたときは、最小化されていれば元に戻したうえで
前面に出してフォーカスするので、必要なときだけ手前に来る。

⌘C 2 回は既定ではオフで、そのあいだはトレイからだけ開く常駐アプリとして動く。
一度有効にしたあと、また設定画面でオフに戻すこともできる。

## モデルの選び方

翻訳に使う PLaMo 3 Translate のサイズは、メイン画面の文体の隣で切り替える（0.8B / 2B / 8B /
31B）。大きいほど訳は良くなるが、遅くなり、メモリを多く使う。**既定は 0.8B**（最初の
ダウンロードを小さく済ませるため。PFN のクライアントの既定は 2B）。選択内容は言語・文体と一緒に即座に保存される。

まだダウンロードしていないサイズを選ぶと、ダウンロード画面に切り替わる。そこで別の
サイズを選び直すこともできる。ダウンロード済みのものはプルダウンに「（未ダウンロード）」が
付かない。モデルの追加・削除は設定画面の「翻訳モデル」から。削除は誤操作を避けるため
2 回押す（「削除」→「本当に削除」）。

選んだモデルは起動時とサイズを変えたときに先に読み込んでおくので、最初の翻訳も
読み込み待ちにならない（[読み込みと保持](how-it-works.md#読み込みと保持)）。

## Claude Code で訳す

モデル欄の一番下の **Claude Haiku 5.5** を選ぶと、手元の `claude` CLI（`claude -p`）で
訳す。Claude Code にログイン（サブスク）しておく必要がある。モデルは `claude-haiku-5-5` に
固定。**このときは文章が Anthropic に送られる。**

設定画面の「Claude Code」で、`claude` の場所（見つからないとき用）と、応答が途切れてから
諦めるまでの秒数を変えられる。「Claude Code を確認」で、見つかるか・新しさ・ログイン済みかを
確かめられる（ネットには出ない）。

## 文体

訳文の文体は「文体: 自動」「です・ます」「だ・である」の 3 つ。PLaMo が文体を受け付けるのは
**翻訳先が日本語のときだけ**なので、それ以外ではプルダウンが無効になる。Claude Haiku 5.5 では
どの言語でも効く（日本語以外では丁寧／くだけた調子として）。

翻訳元が「自動検出」のまま日本語の文章を訳すと、翻訳先が日本語でも英語に訳す。このときは
結果の横に `（日本語 → 英語）` と出る（[日本語を日本語へ](how-it-works.md#日本語を日本語へ)）。

## 設定の保存

その他の設定は歯車ボタンから。**保存ボタンは無く、触った時点でその場で保存される**
（テキスト欄は入力が止まってから、またはフォーカスが外れたとき）。保存先は OS の設定
ディレクトリ配下の `settings.json`
（macOS なら `~/Library/Application Support/dev.hashibadaiki.konjac/`。ソースから
`pnpm tauri dev` で動かしたときだけ `.dev` の付いた別ディレクトリを使う）。

モデルはアプリのデータディレクトリ配下の `models/` に入る（macOS なら
`~/Library/Application Support/dev.hashibadaiki.konjac/models/`。正確な場所は設定画面に出る）。
数 GB あるので、こちらは開発用ビルドとも共有する。

## 長い文章

文字数の上限は設けていない。長い文章は段落ごとに区切って順に訳し、元の区切りでつなぐ。
ただし改行の無い 1 行が長すぎる（約 4,096 トークンを超える）とエラーになるので、途中で
改行を入れる。詳しくは [長い入力](how-it-works.md#長い入力)。
