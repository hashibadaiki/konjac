翻訳モデルをダウンロード

翻訳は Preferred Networks の PLaMo 3 Translate をこの端末の中で動かして行う。 使うには、最初に一度だけモデルをダウンロードする（Hugging Face から取得）。 ダウンロード後はネットに繋がっていなくても翻訳でき、文章はどこにも送られない。

コピー 2 回で開きますか？

⌘C を 2 回押すと、この ウィンドウが出てきて、コピーした文章をその場で翻訳する。この機能を いま有効にするかどうかだけ決めてほしい。

有効にすると、2 回目を検出したその瞬間にクリップボードの本文を読み、 入力欄に入れて翻訳する。端末内モデルなら本文を外部へは送らない。 Claude Code を選んでいるときは Anthropic に送る。 それ以外のときは本文を見ない。パスワードなどをコピーした直後に誤検出が起きれば、 それがウィンドウに表示されることになる。

どちらを選んでも、あとから設定画面で変えられる。

翻訳エンジンは翻訳画面右上のモデル欄で選ぶ。端末内（PLaMo 3 Translate）は 文章を外部へ送らない。Claude Code（Haiku）は手元の claude CLI を 通して Anthropic に送って翻訳する。変更はその場で保存される。

翻訳モデル

大きいほど訳は良くなるが、遅くなり、メモリを多く使う。使うモデルは翻訳画面の右上で選ぶ。 目安として、2B は M1 Max で 400 トークン（日本語で数百字）ほどの訳を約 4 秒で書く（PFN の計測）。 31B はファイルだけで 19 GB 近くあり、メモリに余裕のある Mac 向け。

Claude Code

モデル欄で「Claude Haiku」を選んだときに使う。手元の claude CLI を claude -p で呼び、Claude Code のログイン（サブスク）で翻訳する。 このときは文章が Anthropic に送られる。

起動方法

有効にすると、コピーした内容をこのアプリが読み取ります。 Claude Code を選んでいる間は、その内容が Anthropic に送信されます。

コピー 2 回を検出した瞬間にクリップボードの本文を読み取り、 選んでいるエンジンで翻訳する。端末内モデル（PLaMo 3 Translate）なら 本文を外部へ送ることはない。Claude Code なら claude CLI 経由で Anthropic に送る。 ただしパスワード・アクセストークン・社内文書などがクリップボードに入っている状態で 誤検出が起きれば、それらがウィンドウに表示されることになる。

読み取るのは 2 回目を検出したその瞬間だけで、それ以外のときは本文を見ない （常時見ているのは OS の「変更カウンタ」という数値だけ）。無効のあいだは 読み取りは起きない。訳文も原文もこのアプリはディスクに保存しない。

読み取り: 2 回目を検出した瞬間にクリップボードの本文を読み、 選んでいるエンジンで翻訳する（端末内モデルなら外部へ送らない、Claude Code なら Anthropic に送る）。チェックを外せば、読み取りも止まる。

—

既定はオフ。クリップボード監視は「誰が書いたか」が分からないので、音声入力ソフトなどの 書き込みをコピー 2 回と取り違えることがある。オフのあいだは入力欄に入れるだけで止め、 翻訳は ⌘/Ctrl+Enter か「翻訳」ボタンを押したときだけにする。 キーボード監視のときは ⌘C のキーそのものを見ていて取り違えようがないので、 この設定に関わらず即翻訳する。

⌘ を押したまま C を 2 回にも反応させるには、キーボードを直接 監視する必要がある。macOS の「アクセシビリティ」許可が要る（キーを見るだけで、 入力の書き換えはしない）。DeepL が初回起動時にこれを求めるのも同じ理由。

音声入力ソフトで勝手に反応してしまう場合もこれで直る。 Aqua Voice などはクリップボード経由で文字を貼り付けるため、いまのクリップボード 監視では 2 回コピーしたのと見分けがつかない。キーボード監視は ⌘C のキーだけを 見るので、貼り付け（⌘V）では反応しない。

許可は実行ファイルのパスごとに記録される。 pnpm tauri dev の開発用バイナリと、pnpm tauri build で作った .app は別物として扱われるので、それぞれ許可が要る。未署名 ビルドは中身が変わるだけでも許可が外れるが、署名済みのリリース版なら更新をまたいで残る。

許可したのに切り替わらないときは、一覧に konjac が 2 つ並んでいないか見る。どちらも同じ名前で出るので、入れるのは /Applications の方。開発用の行は再ビルドのたびに中身が変わって勝手に外れるため、入れっぱなしにしても効かない。

この OS ではコピー 2 回を検出できない（macOS と Windows のみ対応）。 ウィンドウを出したまま使うか、トレイアイコンから開き直すこと。

クリップボード変更カウンタ —
コピーを検出した回数 —
他アプリの書き込みとして無視した回数 —
2 回目として起動した回数 —

この画面を開いたままコピーすると、値がその場で動く。

✕ や Esc で閉じても常駐している。トレイ（macOS はメニューバー）のアイコンから 開き直せる。終了もそこから。− は最小化で、こちらはタスクバー （macOS は Dock）に残るのでそこから戻せる。
