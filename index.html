コピー 2 回で開きますか？

⌘C を 2 回押すと、この ウィンドウが出てきて、コピーした文章をその場で翻訳する。この機能を いま有効にするかどうかだけ決めてほしい。

有効にすると、2 回目を検出したその瞬間にクリップボードの本文を読み、 claude CLI 経由で Anthropic に送って翻訳する。 それ以外のときは本文を見ない。パスワードなどをコピーした直後に誤検出が起きれば、 それも送られることになる。

どちらを選んでも、あとから設定画面で変えられる。

翻訳は手元の claude CLI をワンショットで呼び出す。Claude の サブスクにログイン済みなら API キーは要らない。変更はその場で保存される。

起動方法

有効にすると、コピーした内容が Anthropic に送信されます。

コピー 2 回を検出した瞬間にクリップボードの本文を読み取り、手元の claude CLI（Claude Code）経由で Anthropic のサーバへ送って翻訳する。 パスワード・アクセストークン・社内文書などがクリップボードに入っている状態で 誤検出が起きれば、それらが送られることになる。

読み取るのは 2 回目を検出したその瞬間だけで、それ以外のときは本文を見ない （常時見ているのは OS の「変更カウンタ」という数値だけ）。無効のあいだは 読み取りも送信も起きない。訳文も原文もこのアプリはディスクに保存しない。 送信後の扱いは Claude Code のアカウント設定と Anthropic のプライバシーポリシーに従う。

送信先: 2 回目を検出した瞬間にクリップボードの本文を読み、 claude CLI（Claude Code）経由で Anthropic に送って翻訳する。 チェックを外せば、読み取りも送信も止まる。

—

既定はオフ。クリップボード監視は「誰が書いたか」が分からないので、音声入力ソフトなどの 書き込みをコピー 2 回と取り違えることがある。オフのあいだは入力欄に入れるだけで止め、 送信は ⌘/Ctrl+Enter か「翻訳」ボタンを押したときだけにする。 キーボード監視のときは ⌘C のキーそのものを見ていて取り違えようがないので、 この設定に関わらず即翻訳する。

⌘ を押したまま C を 2 回にも反応させるには、キーボードを直接 監視する必要がある。macOS の「アクセシビリティ」許可が要る（キーを見るだけで、 入力の書き換えはしない）。DeepL が初回起動時にこれを求めるのも同じ理由。

音声入力ソフトで勝手に反応してしまう場合もこれで直る。 Aqua Voice などはクリップボード経由で文字を貼り付けるため、いまのクリップボード 監視では 2 回コピーしたのと見分けがつかない。キーボード監視は ⌘C のキーだけを 見るので、貼り付け（⌘V）では反応しない。

許可は実行ファイルのパスごとに記録される。 npm run tauri dev の開発用バイナリと、npm run tauri build で作った .app は別物として扱われるので、それぞれ許可が要る。未署名 ビルドは中身が変わるだけでも許可が外れるが、署名済みのリリース版なら更新をまたいで残る。

許可したのに切り替わらないときは、一覧に konjac が 2 つ並んでいないか見る。どちらも同じ名前で出るので、入れるのは /Applications の方。開発用の行は再ビルドのたびに中身が変わって勝手に外れるため、入れっぱなしにしても効かない。

この OS ではコピー 2 回を検出できない（macOS と Windows のみ対応）。 ウィンドウを出したまま使うか、トレイアイコンから開き直すこと。

その他

翻訳は届いた分から順に表示されるので、長文でも待ち時間は最初の 1 文字までで済む。 この設定は「全体で何秒まで」ではなく「何も届かない状態が何秒続いたら諦めるか」。
